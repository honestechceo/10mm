# 3D rolling socket skins

This directory is used by the 12-frame skin animation loader in game.js.

Each skin must have a subdirectory with frame_00.png through frame_11.png.
For example: skins3d/shop_chrome/frame_00.png.

The animation PNGs are not yet committed here. Extract the provided ZIP and upload the PNGs to their matching paths. Until then, the game uses its original WebP skin sprites.

Do not publish the 3D animation update before checking the image transparency, rolling loop and iPhone performance.
