WHERE'S MY 10MM?! — VERSION 5.2
================================
Includes index.html and transparent PNG assets extracted from the supplied tool artwork.

DEPLOY TO GITHUB
1. Upload index.html to the root of honestechceo/10mm, replacing the existing file.
2. Upload the entire assets/ folder to the root of the same repository.
3. Commit both changes to a feature branch and create a pull request to main.
4. After merging, refresh the GitHub Pages game.

IMPORTANT: Keep the assets/ folder next to index.html. Opening index.html without
the assets folder will fall back to the older canvas illustrations.

Version 5.2 preserves the 200 levels, timer, tap-to-move mechanic, hints, zoom,
and saved progress. Tool graphics are cut from the user-provided reference art.
Some extracted wrench and bolt artwork may need further cropping refinements.
